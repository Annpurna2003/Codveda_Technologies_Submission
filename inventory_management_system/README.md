# Store Management System

A full-stack web application to manage inventory, suppliers, and stock transactions.

## Features
- Staff registration and login based on role
- Manage Suppliers and Items
- Purchase and Issue transactions
-  Ledger Status
- Real-time stock updates

## Technologies
- Frontend: React.js,TailwindCSS
- Backend: Node.js, Express.js
- Database: MongoDB
- API testing: Postman
